Compatibility / Kompatibilitet

English

This application is designed for LG Smart TVs running webOS and supporting LG Developer Mode.

Requirements:
• LG Smart TV with webOS
• LG Developer Mode app
• Free LG account
• Windows 10 or Windows 11
• PC and TV on the same local network

Note:
Not compatible with Android TV, Google TV, Samsung Tizen or other Smart TV platforms.

Norsk

Dette programmet er utviklet for LG Smart-TV-er som kjører webOS og støtter LG Developer Mode.

Systemkrav:
• LG Smart-TV med webOS
• LG Developer Mode-app
• Gratis LG-konto
• Windows 10 eller Windows 11
• PC og TV på samme lokale nettverk

Merk:
Ikke kompatibel med Android TV, Google TV, Samsung Tizen eller andre Smart-TV-plattformer.

Price & license / Pris og lisens

Free to try for 15 days. After that a code is needed: 100 NOK / about 10 EUR (PayPal or Vipps). One code covers one program on one PC and includes bug reports and updates.

Gratis i 15 dager. Deretter trengs en kode: 100 kr / ca. 10 EUR (Vipps eller PayPal). Koden gjelder ett program på én PC og gir rett til å melde feil og få oppdateringer.

Windows warning? / Advarsel fra Windows?

The program is not code-signed, so Windows or your browser may warn you. In the browser choose Keep. In Windows click More info and then Run anyway.

Programmet er ikke kodesignert, så Windows eller nettleseren kan advare. I nettleseren velger du Behold. I Windows klikker du Mer informasjon og så Kjør likevel.
