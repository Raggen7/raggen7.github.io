## Install / Installere

1. Open the program's *Releases* page and download the `..._Setup.exe` file.
2. If Windows shows a blue warning, click **More info** and then **Run anyway**. The programs are not code-signed.
3. Choose the install folder and follow the steps.

1. Åpne programmets *Releases*-side og last ned filen `..._Setup.exe`.
2. Viser Windows en blå advarsel: klikk **Mer informasjon**, så **Kjør likevel**. Programmene er ikke kodesignert.
3. Velg installasjonsmappe og følg trinnene.
